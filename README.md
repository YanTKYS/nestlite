# NestLite パイロット版 README

## 概要

NestLite は、NoteNest / IdeaNest / ChatNest の設計思想を抽出した軽量統合版のパイロットアプリケーションです。

「Chat で発散 → Idea カード化 → Note に整理」という思考の流れを 1 つのアプリ内で自然に使えるかを検証することを目的としています。

## 使い方

### 起動方法

`nestlite/index.html` をブラウザで開くだけです。

```bash
# シンプルにファイルを開く
open nestlite/index.html

# またはローカルサーバーを起動（任意）
python3 -m http.server 8000
# ブラウザで http://localhost:8000/nestlite/index.html にアクセス
```

**注意**: CDN や外部リソースを使用していないため、インターネット接続がなくても動作します。

### 基本フロー

1. **Chat ビュー**でアイデアを書き出す（発散）
   - テキストエリアにメッセージを入力
   - Ctrl+Enter または「送信」ボタンで追加
   - 各メッセージに「カード化」ボタンで Idea カードを作成可能

2. **Idea ビュー**でカードとして整理
   - Chat から作成または直接カード追加
   - タイトル・内容はクリックして直接編集可能
   - タグ付け、ピン留め、アーカイブが可能
   - 複数選択して「ノート作成」でまとめて Note に送れる

3. **Note ビュー**でノートにまとめる
   - Markdown 形式で執筆
   - Idea カードを関連付け可能
   - Markdown エクスポート対応

### データ管理

- **保存**: 「保存 (.nestlite)」ボタンで JSON ファイルをダウンロード
- **読込**: 「読込 (.nestlite)」ボタンで既存ファイルを読み込み
- **新規作成**: 「新規作成」ボタンでデータを初期化
- **エクスポート**: 「Markdown エクスポート」で Markdown 形式で出力

## ファイル形式

`.nestlite` ファイルは JSON 形式です：

```json
{
  "version": "1.0.0",
  "createdAt": "2025-06-06T00:00:00.000Z",
  "updatedAt": "2025-06-06T00:00:00.000Z",
  "chats": [...],
  "ideas": [...],
  "notes": [...]
}
```

詳細なスキーマは `docs/nestlite-pilot-spec.md` を参照してください。

## 機能一覧

### 実装済み機能

#### Chat 機能
- [x] メッセージの追加
- [x] メッセージの表示（時系列順）
- [x] メッセージの削除
- [x] メッセージから Idea カード作成

#### Idea 機能
- [x] カードの手動作成
- [x] Chat メッセージからのカード作成
- [x] カードの編集（タイトル・内容）
- [x] タグの付与・編集（最小限）
- [x] ピン留め（最小限）
- [x] アーカイブ（最小限）
- [x] カードの削除
- [x] カードを Note に送る
- [x] 複数カードを選択してノート作成

#### Note 機能
- [x] ノートの作成
- [x] ノートの編集（Markdown）
- [x] Idea カードの関連付け
- [x] タグの付与（最小限）
- [x] ノートの削除
- [x] Markdown 形式でのエクスポート

#### データ管理機能
- [x] .nestlite ファイルとして保存（ダウンロード）
- [x] .nestlite ファイルの読込（アップロード）
- [x] 新規プロジェクト作成（データ初期化）

### 実装対象外の機能

以下は本パイロット版では実装していません：

- 既存 3 ツール全機能の再実装
- 既存ファイル形式の完全互換
- ファイル関連付け
- インストーラー
- 複数ウィンドウ
- 高度なタスク管理
- 高度なタグ管理（階層タグ、色分けなど）
- クラウド同期
- AI 連携
- リッチテキストエディタ
- 画像・ファイル添付
- 検索機能
- バージョン履歴

## 技術仕様

- **言語**: JavaScript（TypeScript からコンパイルされた同等のコード）
- **依存関係**: なし（バニラ JS のみ）
- **対応ブラウザ**: モダンブラウザ（Chrome, Firefox, Edge, Safari の最新版）
- **データ保存**: クライアントサイド完結、サーバー不要

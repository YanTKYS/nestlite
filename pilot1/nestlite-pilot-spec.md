# NestLite パイロット版 仕様書

## 1. 概要

NestLite は、NoteNest / IdeaNest / ChatNest の設計思想を抽出した軽量統合版のパイロットアプリケーションである。

### 1.1 目的
「Chat で発散 → Idea カード化 → Note に整理」という思考の流れを 1 つのアプリ内で自然に使えるかを検証する。

### 1.2 位置づけ
- 既存 3 ツールの置き換えではない
- 本格実装前の概念検証用プロトタイプ
- 単一 HTML ファイルで動作する静的アプリ

## 2. 技術方針

### 2.1 実装言語
- TypeScript（ただしビルド成果物のみを配布）
- 実行環境には Node.js/npm を要求しない

### 2.2 依存関係
- CDN は使用しない
- 外部 API は使用しない
- サーバ処理は不要
- ブラウザの標準機能のみを使用

### 2.3 データ保存
- 既存の `.notenest` / `.ideanest` / `.chatnest` ファイルは直接読み書きしない
- NestLite 独自の `.nestlite` JSON 形式で保存・読込
- ローカルストレージまたはファイルダウンロード/アップロードで管理

## 3. データ構造

### 3.1 .nestlite ファイル形式

```json
{
  "version": "1.0.0",
  "createdAt": "2025-06-06T00:00:00.000Z",
  "updatedAt": "2025-06-06T00:00:00.000Z",
  "chats": [
    {
      "id": "chat-001",
      "role": "user",
      "content": "メッセージ内容",
      "timestamp": "2025-06-06T00:00:00.000Z"
    }
  ],
  "ideas": [
    {
      "id": "idea-001",
      "title": "カードタイトル",
      "content": "カード内容",
      "tags": ["タグ 1", "タグ 2"],
      "pinned": false,
      "archived": false,
      "sourceChatId": "chat-001",
      "createdAt": "2025-06-06T00:00:00.000Z",
      "updatedAt": "2025-06-06T00:00:00.000Z"
    }
  ],
  "notes": [
    {
      "id": "note-001",
      "title": "ノートタイトル",
      "content": "マークダウン形式の本文",
      "ideaIds": ["idea-001", "idea-002"],
      "tags": ["タグ 1"],
      "pinned": false,
      "archived": false,
      "createdAt": "2025-06-06T00:00:00.000Z",
      "updatedAt": "2025-06-06T00:00:00.000Z"
    }
  ]
}
```

### 3.2 データエンティティ

#### ChatMessage
| フィールド | 型 | 説明 |
|-----------|-----|------|
| id | string | ユニーク ID |
| role | "user" | 発言者ロール（現在は user のみ） |
| content | string | メッセージ内容 |
| timestamp | string | ISO8601 形式のタイムスタンプ |

#### IdeaCard
| フィールド | 型 | 説明 |
|-----------|-----|------|
| id | string | ユニーク ID |
| title | string | カードタイトル |
| content | string | カード内容 |
| tags | string[] | タグ配列 |
| pinned | boolean | ピン留めフラグ |
| archived | boolean | アーカイブフラグ |
| sourceChatId | string? | 元になった Chat メッセージ ID |
| createdAt | string | 作成日時 |
| updatedAt | string | 更新日時 |

#### Note
| フィールド | 型 | 説明 |
|-----------|-----|------|
| id | string | ユニーク ID |
| title | string | ノートタイトル |
| content | string | マークダウン形式の本文 |
| ideaIds | string[] | 関連する Idea カード ID 配列 |
| tags | string[] | タグ配列 |
| pinned | boolean | ピン留めフラグ |
| archived | boolean | アーカイブフラグ |
| createdAt | string | 作成日時 |
| updatedAt | string | 更新日時 |

## 4. UI 構成

### 4.1 レイアウト
- シングルページアプリケーション
- 上部にタブナビゲーション（Chat / Idea / Note）
- 各ビューがタブ切り替えで表示

### 4.2 Chat ビュー
- メッセージ一覧表示エリア
- 入力フォーム（テキストエリア + 送信ボタン）
- 各メッセージに「Idea カード化」ボタン
- メッセージ削除機能

### 4.3 Idea ビュー
- カードグリッド表示
- カード追加ボタン（手入力）
- 各カードに：
  - タイトル編集
  - 内容編集
  - タグ表示・編集
  - ピン留めトグル
  - アーカイブトグル
  - 「Note に送る」ボタン
  - 削除ボタン
- チェックボックスで複数選択可能

### 4.4 Note ビュー
- ノート一覧表示
- ノート作成ボタン
- ノート編集画面：
  - タイトル入力
  - Markdown エディタ（簡易テキストエリア）
  - Idea カード選択エリア（チェックボックス）
  - タグ入力
  - プレビュー表示（任意）
- Markdown エクスポートボタン

### 4.5 グローバル操作
- データ保存（.nestlite ダウンロード）
- データ読込（.nestlite アップロード）
- 新規作成（データクリア）

## 5. 機能要件

### 5.1 Chat 機能
- [ ] メッセージの追加
- [ ] メッセージの表示（時系列順）
- [ ] メッセージの削除
- [ ] メッセージから Idea カード作成

### 5.2 Idea 機能
- [ ] カードの手動作成
- [ ] Chat メッセージからのカード作成
- [ ] カードの編集（タイトル・内容）
- [ ] タグの付与・編集（最小限）
- [ ] ピン留め（最小限）
- [ ] アーカイブ（最小限）
- [ ] カードの削除
- [ ] カードを Note に送る

### 5.3 Note 機能
- [ ] ノートの作成
- [ ] ノートの編集（Markdown）
- [ ] Idea カードの関連付け
- [ ] タグの付与（最小限）
- [ ] ピン留め（最小限）
- [ ] アーカイブ（最小限）
- [ ] ノートの削除
- [ ] Markdown 形式でのエクスポート

### 5.4 データ管理機能
- [ ] .nestlite ファイルとして保存（ダウンロード）
- [ ] .nestlite ファイルの読込（アップロード）
- [ ] 新規プロジェクト作成（データ初期化）

## 6. 非機能要件

### 6.1 パフォーマンス
- 初期表示は 1 秒以内
- 操作感は軽快であること

### 6.2 互換性
- モダンブラウザ（Chrome, Firefox, Edge, Safari の最新版）
- 既存ファイル形式との互換性は不要

### 6.3 セキュリティ
- クライアントサイド完結
- データはユーザー端末内に留まる

## 7. 実装スコープ外

以下は本パイロット版では実装しない：
- 既存 3 ツール全機能の再実装
- 既存ファイル形式の完全互換
- ファイル関連付け
- インストーラー
- 複数ウィンドウ
- 高度なタスク管理
- 高度なタグ管理（階層タグ、色分けなど）
- クラウド同期
- AI 連携
- リッチテキストエディタ
- 画像・ファイル添付
- 検索機能
- バージョン履歴
